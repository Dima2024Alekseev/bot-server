# VPS Telegram bot

Бот предназначен для Linux VPS с PM2 и управляет одним приложением PM2. Команды доступны только двум указанным администраторам в личных чатах. Бот вызывает только фиксированные команды PM2 для заданного имени процесса; произвольные команды ОС через Telegram не выполняются.

## Как узнать имя приложения в PM2

Подключитесь к VPS под тем же Linux-пользователем, от которого запущено серверное приложение, и выполните:

```sh
pm2 list
```

Скопируйте значение из столбца `name` нужной строки. Например, для команды запуска `pm2 start server.js --name game-server` укажите `game-server`. Бот не сможет управлять процессом, если запущен под другим Linux-пользователем или подключён к другому PM2 daemon.

## Настройка

1. Установите Node.js 18 или новее и PM2 для пользователя, который управляет приложением.
2. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен Telegram-бота;
   - `ADMIN_CHAT_IDS` — два Telegram chat ID через запятую;
   - `PM2_PROCESS_NAME` — точное имя из столбца `name` команды `pm2 list`.
3. Установите зависимости и запустите бота от того же Linux-пользователя, что запускает сервер:

   ```sh
   npm install
   npm start
   ```

Не запускайте бота от `root`. Если используете нестандартный `PM2_HOME`, задайте его и для процесса бота, чтобы он подключался к тому же PM2 daemon.

Файл `.env` не следует добавлять в Git или пересылать в чаты. Список напоминаний сохраняется в `data/reminders.json`; каталог `data` нужно сохранять при обновлении проекта.

## Команды

- `/start` — показать панель с кнопками;
- `/status` — состояние приложения PM2;
- `/logs` или `/logs 50` — последние строки логов (до 100);
- `/startserver` — запустить приложение, сохранённое в PM2;
- `/stopserver` — остановить приложение;
- `/restartserver` — перезапустить приложение;
- кнопка `⏰ Напоминание` — выбрать интервал 10 минут, 30 минут, 1 час или 1,5 часа, затем ввести текст. Время можно выбрать только кнопками;
- `/reminders` — показать свои напоминания;
- `/cancelreminder ID` — отменить своё напоминание.

Команда запуска использует `pm2 restart` для выбранного приложения: запись приложения должна оставаться в PM2 (не удаляйте её через `pm2 delete`). Если процесс остановлен, но сохранён в PM2, эта команда запустит его снова.

Кнопки остановки и перезапуска запрашивают подтверждение перед выполнением.

Напоминание через кнопки планируется относительно текущего времени. Когда срок наступит, бот отправит текст обоим администраторам. Если VPS или бот выключен в этот момент, просроченное напоминание будет отправлено после запуска бота.
